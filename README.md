# Fashion Intelligence Platform

AI-powered fashion analysis platform with intelligent fit checking and style recommendations.

## 📁 Project Structure

```
d:\3Dmodel/
├── api/                    # Backend API (FastAPI)
├── website/                # Frontend (React + TypeScript)
├── integrations/           # AI services & analyzers
├── tests/                  # All test files
├── docs/                   # Documentation
├── scripts/                # Utility scripts
└── archive/                # Old/deprecated files
```

## 🚀 Quick Start

### Backend
```bash
cd api
python app.py
```

### Frontend
```bash
cd website
npm start
```

## ✨ Features

- **AI Fit Checker**: Analyze clothing fit using real sizing charts
- **Body Measurements**: SMPL-based 3D body scanning
- **Style Analysis**: AI-powered fashion recommendations
- **Color Matching**: Skin tone detection & color harmony
- **Trend Intelligence**: Real-time fashion trend analysis

## 🛠️ Tech Stack

**Backend**: Python, FastAPI, SQLModel, Groq AI
**Frontend**: React, TypeScript, Tailwind CSS, Framer Motion
**AI**: Groq Vision (Llama 4), OpenCV, SMPL
