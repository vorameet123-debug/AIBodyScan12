# Known Issues & Solutions
# ===============================================
# 1. If "chumpy" fails:
#    - Python 3.13: Needs manual fixes (see SETUP_GUIDE.md)
#    - Python 3.10-3.11: Should work fine
#
# 2. If "pyrender" fails (OpenGL errors):
#    - System sets PYOPENGL_PLATFORM='osmesa' automatically
#    - Rendering is optional, measurements work without it
#
# 3. If "yolov3" download fails:
#    - System uses urllib fallback on Windows
#    - Manual: Download from PARE repository
#
# 4. If PyTorch CUDA errors:
#    - System automatically uses CPU
#    - GPU not required for this application
